# MG Büromöbel AG – Lerncheck

Eine responsive, statische HTML-Lernübung zum fiktiven Modellunternehmen MG Büromöbel AG.

## Lokal ansehen

`index.html` im Browser öffnen. Es werden keine externen Bibliotheken geladen und keine Antworten an einen Server übertragen.

## Mit GitHub Pages veröffentlichen

1. Ein öffentliches GitHub-Repository erstellen.
2. `index.html` und `README.md` in den Hauptordner des Repositorys hochladen.
3. In **Settings → Pages** die Bereitstellung aus dem Branch `main` und dem Ordner `/ (root)` auswählen.
4. Nach dem Deployment die von GitHub angezeigte Pages-Adresse öffnen und die drei Übungen testen.

Das Repository und die daraus veröffentlichte Seite sind öffentlich zugänglich.
